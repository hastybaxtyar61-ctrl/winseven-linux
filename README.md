# WinSeven Linux 🪟

> Bringing back the best desktop UI ever made, backed by pure Arch Linux.

### 🚧 Under Active Development / Coming Soon 🚧

Let's be honest: Windows 7's Aero aesthetic was peak UI design, but relying on sketchy post-install shell scripts that mess up your Arch installation isn't the move.

**WinSeven Linux** is a personal project to build a clean, out-of-the-box ISO using `archiso`. The goal is simple: boot up, get a rock-solid KDE Plasma 6 desktop with real glass blur and Windows 7 vibes, and have `wine-staging` ready to roll for games and old software without hours of tweaking.

#### What's in the works:
* **Pure Arch Foundation:** Built straight from `archiso` for zero extra bloat.
* **Authentic Aero UI:** Pre-configured Kvantum glass themes, classic taskbar, and proper Segoe fonts out of the box.
* **Ready for Windows Apps:** `wine-staging` + DXVK baked in so you can run software immediately.
* **Lightweight:** Tailored to run smooth even on low-end hardware (testing on a humble Chromebook!).

*Early ISO releases are coming as soon as the base build is cooked. Stay tuned!*
